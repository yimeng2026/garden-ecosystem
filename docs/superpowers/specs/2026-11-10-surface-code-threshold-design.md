# 表面码真实阈值基准设计

**日期**：2026-11-10  
**范围**：只建立一项独立、可复验的 Stim＋PyMatching 基准，不宣称复原作者未公开的模拟，也不预先支持或反对论文的 1.03% 数值。

## 备选方案与决定

1. **完整复现论文三**：需要原始电路、噪声、种子、解码器和有限尺寸标度配置；当前缺失，不能诚实执行。
2. **独立电路级基准（采用）**：用 Stim 生成的公开 surface-code 电路和 PyMatching MWPM，固定全部输入并公开结果。优点是可执行、可复核；局限是结果只适用于本协议。
3. **保留公式自检**：只能验证预设标度函数的单调性，没有新增逐 shot 证据，不采用。

## 预注册协议

- 电路：`stim.Circuit.generated("surface_code:rotated_memory_x")`。
- 码距：`[3, 5, 7, 9]`；每码距 `rounds=distance`。
- 物理错误率：`[0.004, 0.005, 0.006, 0.007, 0.008, 0.009, 0.010]`。
- 噪声：`after_clifford_depolarization`、`before_round_data_depolarization`、`after_reset_flip_probability`、`before_measure_flip_probability` 均取同一 `p`。
- 解码：`circuit.detector_error_model(decompose_errors=True)` 后交给 `pymatching.Matching.from_detector_error_model`。
- 采样：每点 20,000 shots；每个 `(distance,p)` 使用由协议种子和网格索引决定的独立种子。
- 指标：逻辑错误 shot 数、错误率及 95% Wilson 区间。零噪声另作健全性检查。
- 阈值：对 `log10(p_L)` 做分段线性插值，计算各码距对交叉点的中位数和范围。它是探索性交叉估计，不是有限尺寸标度拟合，也不提供伪装成统计置信区间的误差棒。

## 组件

1. 协议 JSON：冻结版本、网格、噪声、shots、种子和估算规则。
2. 运行脚本：执行电路采样与解码，输出逐点 JSON、CSV 和 SVG。
3. 独立复验脚本：只读结果，重算错误率、Wilson 区间、交叉估计和协议哈希。
4. 测试：纯函数边界、合成曲线交叉、协议校验、零噪声与小型真实电路冒烟。

## 错误处理与边界

- 非法码距、概率、shots、空网格、无交叉和输出形状不匹配必须显式失败。
- 缺少 Stim／PyMatching 时报告依赖缺失，不回退到预设公式或伪造数据。
- 单次前台运行有界，不保留后台进程；依赖只装入被忽略的 `.tools` 环境。
- 结果不得直接否定论文在不同噪声模型下的 1.03%；只能指出当前仓库没有支持该数值的原始逐 shot 证据，并提供新的独立对照。

## 验收

- 新增测试先按预期失败，实现后全部通过。
- 28 个网格点全部有真实结果和 Wilson 区间，SVG 与 JSON／CSV 数值一致。
- 独立复验返回零差异；协议哈希和依赖版本一致。
- 最终报告包含实际命令、退出码、运行边界和对论文三的具体修订建议。
