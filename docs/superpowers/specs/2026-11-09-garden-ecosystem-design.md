# Garden Ecosystem 独立适配层设计

日期：2026-11-09
状态：依据所有者此前“独立新开仓库、借鉴并验证、全面推进”的明确授权实施；自动权限模式下不再重复询问同一范围。

## 1. 目的与边界

将 MeowCode、AgentWorld、Qwen-AgentWorld、Gamma-World、FudanDISC/SocialAgent 和王斌 MUFPF 的可验证工程思想，转化为千界花园可调用的轻量 Python 接口。不是复制这些项目，也不是宣称已复现其模型、物理结论或基准成绩。

独立仓库 `garden-ecosystem`，不修改主花园的 Next.js/Prisma 数据模型，不重新实现蜂群和现有供应商池。首版仅依赖 Python 标准库。上游源码、模型权重、真实密钥和运行环境均不纳入发布包。

## 2. 方案比较

1. 整体搬入：速度快但带来 GPL 衍生义务、复杂运行时、重复调度与潜在供应链风险，不采用。
2. 只写报告：无行为改变，不满足实际使用，不采用。
3. 原创窄接口适配（采用）：只保留可独立验证的机制；明确接口和许可证边界，失败默认不执行。

## 3. 模块与数据流

### 3.1 `providers.py`

`ProviderProfile` 声明模型、协议、上下文窗口、输出上限和显式回退顺序。`FailureKind` 将异常分为 abort、auth、invalid_request、not_found、context_overflow、rate_limit、server、timeout、network。仅 rate_limit/server/timeout/network 可自动回退；其余直接返回失败。

调用方提供传输函数，生产传输由接口注入；默认示例仅用 mock。密钥通过环境变量名解析，配置只保存变量名，错误、状态和日志通过统一脱敏函数处理。临时注入作用域退出时恢复原值或删除新值。不得把密钥写入文件或日志。

### 3.2 `context.py`

保守估算中英文混合文本 token；稳定规范 JSON 的 SHA-256 用作前缀指纹。真实用量锚点必须同时匹配模型与精确前缀，否则退回估算。输出预算为 `min(配置上限, 窗口-输入-工具-安全余量)`；可用值低于最小输出预算时抛出 `BudgetExceeded`，不伪造可用空间。

工具输出治理分为：保留小结果；对长结果保留头尾并明确省略；超限结果只给可定位的本地引用。本地引用限制在调用者显式给定的工作区中，拒绝绝对路径逃逸和 `..`。区间读取以规范化参数去重，缓存键保持内容寻址稳定。摘要只标记为摘要，不冒称原文。

### 3.3 `reliability.py`

`Action` 包含主体、工具、目标、参数和是否改变世界。策略返回 `ALLOW`、`DENY`、`ASK` 或 `MODIFY`；默认写操作和 shell 为 DENY。MODIFY 的 `executable=False`，建议必须再次走门禁。ASK 使用一次性、绑定动作指纹的批准票据，不能拿批准 A 的票据执行 B。

执行入口只执行明确的 ALLOW 或有匹配票据的 ASK；DENY、未批准 ASK、MODIFY 均不能到达执行器。审计仅记录脱敏后的目标，且记录实际是否执行。

### 3.4 `worlds.py`

`PortableAgent` 含稳定 ID、生命周期、属性、能力和扩展字段。`WorldAdapter` 协议提供校验、暂存、提交、移除和快照；`MemoryWorld` 提供可复现的参考实现。

迁移顺序：源快照→目标校验→源冻结/移除→目标暂存→提交。任一步失败都先撤销目标暂存/提交，再恢复源；回滚也失败时返回 `needs_manual_recovery=True`，保留可读错误，不宣称已恢复。`self_test` 在隔离副本上做导入导出一致性检查，不污染真实世界。

### 3.5 `evaluation.py`

领域固定为 MCP、Search、Terminal、SWE、Android、Web、OS。输入为带领域、参考观察和预测观察的结构化样本；评分函数由调用方注入。五个维度为 format、factuality、consistency、realism、quality，每项范围 0–100，缺失或非有限值报错。分别报告每领域均值和宏平均，不把样本数量不同造成的加权平均冒称总体能力。可序列化每次模型与 judge 的脱敏配置指纹，支持复现。

`SharedWorld` 保留同步 agent 轴、每 agent 观察、共享版本与只经 hub 传递的消息，体现 Gamma-World 的架构思想；不包含其神经网络或性能声明。

### 3.6 `learning.py`

学习默认关闭。记录只含说明性候选，不接受代码、工具定义、凭证、配置修改或自动可执行内容。候选状态为 tentative→active→retired；active 需至少两个不同任务/日期的帮助证据且没有未解决伤害证据。支持正反对照记录与回滚；record 接口不能执行命令或修改花园配置。

### 3.7 `research.py`

登记假设、候选参数域、外部数据来源、排除理由和负结果。预登记冻结后生成内容哈希，后续预测结果追加而非覆盖；支持“参数内生、外部标定、数值估计、待检验”分层。该模块只管理证据，不将上游理论声明自动认定为事实。

### 3.8 `demo.py` / `__main__.py`

离线演示串起预算拒绝、故障切换、审批拒绝、迁移回滚、共享世界、七领域评测空报告和学习禁用状态。结果写 stdout；只有用户显式指定输出路径时才写文件，且必须是本项目的 `artifacts/` 内路径。

## 4. 与千界花园接口

Python 包暴露上述类；`garden_ecosystem.bridge` 提供不含密钥的 `capabilities()` 和 `health()` 字典。主花园后续可通过其受控 Python 服务调用，HTTP/SSE 留在主花园。此次不把 HTTP 服务、前端或数据迁移塞进新仓库。

## 5. 许可证与安全

- 新代码采用 MIT，附 `NOTICE.md` 列明架构灵感来源和固定提交。
- 不复制 MeowCode 的 GPL-3.0 实现；其行为只作为问题研究参考，重新设计不足部分。
- AgentWorld MIT、Qwen-AgentWorld/Gamma-World Apache-2.0 的来源在 NOTICE 注明。
- MUFPF 同时存在 CC-BY-4.0 与 MIT 文件；不复用其代码、论文段落，仅借鉴证据治理思路并注明其理论与物理声明未独立验证。
- MASER、`yizhengzhang1/agent_world` 和清单中未声明许可证项目不复制或再分发。
- 默认无网络、无 shell、无写操作、无学习、无模型权重下载；示例使用虚构密钥和 mock。

## 6. 验证

标准库 `unittest` 覆盖正常路径和负例：各故障分类、回退上限与去重、密钥脱敏/清理、精确锚点、预算溢出、路径逃逸、四态门禁、票据绑定、迁移故障与双重故障、稳定 ID、往返自检、七领域报告、非有限分数拒绝、hub 版本、学习状态门槛与危险候选拒绝、预登记不可变和负结果。CLI  smoke test 输出合法 JSON。

发布门禁：完整测试通过；`compileall` 通过；检查无真实密钥、无上游源码/权重；git diff 审核；许可证与实现来源一致。只有完成上述检查才提交、推送。
