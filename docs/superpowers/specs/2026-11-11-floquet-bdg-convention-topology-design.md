# Floquet–BdG 物理约定修复与联合拓扑诊断设计

## 目标与问题

现有 `research/floquet-bdg/floquet_bdg.py` 的 `majorana_k` 使用 `K[a,b]=-μ`、`(Δ−γ)/2` 和 `−(Δ+γ)/2`。按照该模块自己声明的 `H=iΣK_rsΓ_rΓ_s`，完整的反对称求和包含 `ab` 与 `ba` 两项，因此这些直接矩阵元应各再除以 2。当前 `U=expm(-4KT)` 可能将目标哈密顿量的时间演化放大两倍。

旧静态零空间测试对全局因子不敏感，因此不能排除此问题。旧的 π 模通过和 0 模未决结论都暂停用于目标参数 `(γ,Δ,μ0,μ1,ω)=(1,1,2.5,0.2,7)`，直到独立 Fock 检验和重算完成。

## 路线比较与选择

1. **仅延长开放链**：计算量小，但不能发现全局物理因子错误，也不能独立给出体拓扑，不采用为第一步。
2. **Fock 约定门＋周期链 winding＋开放链复核（采用）**：先证明二次型矩阵与真实费米子哈密顿量一致，再计算体拓扑和端点候选。能区分实现错误、体近简并和有限尺寸效应。
3. **直接计算断开纠缠熵**：可提供额外边缘指标，但引入更多态制备和分区约定；在 Fock 一致性未通过前会放大错误，暂后置。

## 一、不可绕过的物理约定门

### 1. 单格点解析检验

采用 `a=c+c†`、`b=−i(c−c†)`，则 `iab=2n−1`，目标 `H=−μ(2n−1)=−iμab`。完整矩阵元必须为：

```text
K[a,b] = −μ/2, K[b,a] = +μ/2.
```

单格点 Heisenberg 演化为：

```text
a(t) = cos(2μt)a + sin(2μt)b
b(t) = −sin(2μt)a + cos(2μt)b.
```

因此 `expm(-4Kt)` 的第一个非对角元必须是 `sin(2μt)`，不是 `sin(4μt)`。同时用两维 Fock 空间直接计算 `exp(iHt)Γexp(−iHt)`，不得只验证矩阵指数自身。

### 2. 双格点 Fock 矩阵检验

在 `|00>, c1†|00>, c2†|00>, c1†c2†|00>` 基底下，用 Jordan–Wigner 符号构造 `c1=|0><1|⊗I`、`c2=Z⊗|0><1|`。直接构造：

```text
H = −γ(c1†c2+c2†c1) + Δ(c1c2+c2†c1†) − μΣ_j(2n_j−1).
```

再构造四个 Majorana 算符及 `iΣK_rsΓ_rΓ_s`。对非零 `μ,γ,Δ` 的一般取值，两个 4×4 Fock 哈密顿量必须逐元素一致，而不只比较零模或能谱。

由此得到当前模块声明约定下的正确实空间矩阵：

```text
K[a_j,b_j] = −μ/2
K[a_j,b_(j+1)] = (Δ−γ)/4
K[a_(j+1),b_j] = −(Δ+γ)/4
```

其余元素由反对称性给出。旧模块和旧结果不覆盖；修正实现写入 `research/floquet-bdg-convention/`。若上述 Fock 检验不支持该推导，则停止后续拓扑实现并重新审查符号。

### 3. 文献映射与旧结果勘误

Thakurathi et al., arXiv:1303.2300v2 的 Eq. (17)–(23) 给出 `da/dt=4Ma` 和对称化 Floquet 算符；其 Majorana 顺序及 hopping 符号必须在适配表中显式记录，不能直接复制正负号。

在 `research/floquet-bdg/ERRATA.md` 新增勘误，说明旧实现的因子疑点、受影响参数、旧结论暂停范围和新交付位置。旧 `results.json`、图件和 Word 保持原始字节，不能删除或静默改写。

## 二、独立周期链拓扑诊断

### 1. Bloch Floquet 算符

适配当前 `−γ` hopping 约定，使用：

```text
h(k) = 2(−γ cos k − μ0)τ_z + 2Δ sin k τ_y
U(k) = exp(i μ1 τ_z) exp(−i h(k)T) exp(i μ1 τ_z)
T = 2π/ω.
```

这与 Thakurathi Eq. (23) 的 hopping 符号替换相对应。必须另行核对 `k=0` 和 `k=π`，恢复：

```text
b0 = 4(μ0−γ)/ω + 2μ1/π
bπ = 4(μ0+γ)/ω + 2μ1/π.
```

当前限定域 `μ0>γ>0, 0<μ1<π/2` 中，严格位于二者之间的偶／奇整数分别给出 `p0/pπ`。主算例仍要求 `p0=pπ=1`。

### 2. 有效 Hamiltonian 与 winding

对 `U(k)` 取唯一 `0<φ(k)<π` 的 `U=cosφ I−i sinφ n·τ` 表示，避免直接 `logm` 的分支切割：

```text
φ = arccos(Tr U / 2)
n_y = (U_01*−U_01)/(2 sinφ)
n_z = (U_11−U_00)/(2i sinφ)
α(k) = atan2(n_y,n_z)
W = [unwrapped α(π)−unwrapped α(−π)]/(2π).
```

这里 `U_01*` 表示 `U[0,1]` 的复共轭。检查 `min sinφ` 和 `U(k)` 的 unitarity；接近 `±I` 时 winding 不可定义，必须返回 `gapless_or_undefined`，不能补值。

主算例文献预期 `|W|=2`，静态 `μ1=0, μ0=2.5` 控制预期 `W=0`。分别用 `Nk=512,1024,2048,4096` 的中点动量网格计算，要求 winding 与最近整数的偏差和相邻网格差均小于 `1e-6`。另以 `scipy.linalg.logm` 在远离分支奇点的抽样点交叉检查 `n_y,n_z`，不拿同一矩阵重复对角化冒充独立验证。

### 3. 解析与数值边界

`|W|=2` 只给出 0／π 总数；`p0=1,pπ=1` 才分别给出端点计数。二者一致仍不是材料证明，也不能自动证明有限开放链的候选分离。

## 三、修正后的开放链与近简并诊断

1. 使用通过 Fock 门的修正矩阵，重算 `N=40,80,160`，必要时增加 `N=320`；保留全部本征值，不只保存预期候选。
2. 对 `λ=+1/−1` 各输出最近四对共轭本征值的距离、端点权重、左／右权重和 IPR，避免把第二对拓扑边缘模误标为体模。
3. 保留旧联合阈值 `separation<0.1`、`edge_weight>0.5` 作对照，但先根据体不变量和全部近零对说明候选归属。不得因结果改变而事后修改旧阈值。
4. 若修正后 0 模通过原判据，明确这是修复实现错误后的新结果；若仍未通过，记录体拓扑与开放链判据之间的剩余差异，不宣称问题已解决。
5. π 模也必须从头重算；旧通过结果不能因旧错误可能影响较小而直接继承。

## 设计自审

- 范围是单一模型约定修复及联合诊断，没有引入纠缠熵或材料计算等额外子项目。
- 单格点和双格点 Fock 检验分别约束 onsite 与 hopping／pairing；拓扑计算不能在检验失败时继续。
- winding 的公式、分支、动量网格、控制组和验收阈值均已固定；开放链的旧阈值不被事后调整。
- 所有旧结论的暂停、旧证据的保留和新旧产物的关系均明确，无占位符或“默认正确”的隐含前提。
