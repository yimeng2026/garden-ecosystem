# TBC dynamical winding：静态优先、洁净先行、无序后置

## 目标

在现有 Fock 校验的二次型 Kitaev 模型上，使用 twisted boundary condition（TBC）计算 dynamical winding，验证静态拓扑／平凡和洁净 kicked 极限，再决定是否可用于无序候选。不得继续采用未通过静态基准的 DEE 管线，也不得把联合候选判据改名为拓扑证明。

## 路线比较

1. **DEE**：当前静态基准失败且两条实现路径不一致，暂停使用。
2. **TBC dynamical winding（采用）**：直接复用 Majorana 二次型矩阵和周期传播，能检查 chiral 块结构、静态 winding、洁净 kicked 计数和奇点。
3. **实空间 flattening／Bott 型指标**：可作为后续独立交叉方法，但需额外的投影与逆矩阵约定，本轮不同时实现，避免扩大未验证范围。

原始依据：Mondal et al., arXiv:2207.11928v2，Eq. (7)–(16)；Thakurathi et al., arXiv:1303.2300v2 的 Floquet 拓扑不变量。

## 一、Chiral 与 TBC 矩阵约定

在 `(a1,b1,...,aN,bN)` Majorana 基下，使用：

```text
S = diag(-1,+1,-1,+1,...,-1,+1).
```

要求 `S²=I`、`S K S⁻¹ = −K`，其中 `K` 是已经通过一／双格点 Fock 检验的实反对称矩阵。该关系同时用于静态 `K(μ)` 和 kicked 自由演化，不能用未校验的旧矩阵。

TBC 只修改连接第 N 与第 1 个格点的键，附加总通量相位 `exp(iθ)`，反向键取相反符号的复共轭。固定使用：

```text
Kθ[a_N,b_1] = exp(iθ) (Δ−γ)/4
Kθ[a_1,b_N] = −exp(iθ) (Δ+γ)/4
Kθ[b_1,a_N] = −Kθ[a_N,b_1]
Kθ[b_N,a_1] = −Kθ[a_1,b_N].
```

要求：

```text
K(0) = K, K(θ+2π) = K(θ), K(θ)† = −K(θ).
```

`U(θ)` 必须为 unitary，不能强制保持实正交。选择边界相位是规范之一，不以特定 site-phase 规范冒充物理结果；只有规范无关的 winding 才能进入报告。

## 二、时间演化与周期化

采用与既有端点谱一致的对称 kicked 时间帧。令 `H=exp[-2K(μ1)]` 为半 kick、`F(t)=exp[-4K(μ0)t]`：

```text
U_step(0) = I                         （端点参考定义）
U_step(t) = F(t) H,       0 < t < T   （时间有序的部分周期传播）
U_step(T) = H F(T) H                  （完整对称 Floquet 算符）。
```

不能把完整算符的右端半 kick 提前到每个中间时刻，也不能用 `K_full F(T)` 替代对称帧：当 kick 与自由演化不对易时，后者不满足 `S U(T) S⁻¹=U(T)⁻¹`。实测错误的全 kick 起点协议在洁净链上的半周期对称误差约为 `0.34–0.56`；上述时间有序对称帧在代表点将 0／π 误差降至约 `3.2e-15／3.5e-15`，且保持 unitary。`U_step(0)=I` 是跨端点 kick 的参考点定义，不声称右极限不含半 kick。

对 `U_step(T)` 对角化，写 `λ=e^{-iφ}`，其中无量纲准能相位 `φ=-arg(λ)∈[-π,π]`，能量为 `E=φ/T`。按 `φ<0`（valence）和 `φ≥0`（conduction）选择有效相位：

```text
φ_eff,valence    = 2ε−|φ|
φ_eff,conduction = |φ|−2π
P_ε(t) = Q diag[exp(+i φ_eff t/T)] Q†
U_ε(t) = U_step(t) P_ε(t).
```

`Q` 来自酉 Schur 分解 `U_step(T)=QΛQ†`，避免近简并时普通本征向量的非正交性破坏谱函数的 unitary。conduction 的整体 `−2π` 换支不改变 `P_ε(T)=U_step(T)⁻¹`，但决定半周期结构：静态时 `U_0(T/2)=sign(H)` 为反 chiral 块，`U_π(T/2)=−I` 为 chiral 对角块；若省略该换支，两者会错误退化为 `I` 和 `sign(H)`。

这里 `P_ε(t)` 就是 `[U_step(T)]_ε^{-t/T}`。直接相乘可得：valence 在 `t=T` 时为 `exp(i|φ|)exp[i(2ε−|φ|)]=exp(2iε)=1`，conduction 为 `exp(−i|φ|)exp[i(|φ|−2π)]=1`。因此 `U_ε(0)=U_ε(T)=I`，并应满足 `U_ε(t+T)=U_ε(t)`。

原文 Eq. (8) 印出的负指数若与其前述 `U_step|ψ⟩=exp(−iE′T)|ψ⟩` 一起直接代入，不能满足上述端点恒等式。本实现采用由 Eq. (7) 的负分数幂和端点恒等式唯一确定的正指数形式，并用半周期 chiral 结构再次筛选；不把该记号差异静默当成已验证的文献复现。不得用主对数任意换支而不检查周期结构。

在 chiral 基下，半周期结构必须独立验证：

```text
S U_0(T/2) S⁻¹ = −U_0(T/2)  → off-diagonal blocks U_0±
S U_π(T/2) S⁻¹ = +U_π(T/2)  → diagonal blocks U_π±.
```

若块结构不成立，则周期化、kick 时间起点或本征求值约定错误，不能继续计算 winding。

## 三、Winding 与奇点处置

TBC winding 使用：

```text
W_ε = |±(i/2π) ∫_{-π}^{π} Tr[(U_ε±(θ))^{-1} ∂θ U_ε±(θ)] dθ|.
```

使用周期网格 `θ_j=-π+2πj/M, j=0,...,M−1`，中心差分采用 `np.roll` 环绕端点，梯形积分等价于对格点求和乘以实际步长。名义 `dθ=0.05` 与 `0.025` 分别取 `M=round(2π/dθ)`，实际步长 `2π/M` 写入结果，不把端点 `π` 重复计入。要求相邻网格 winding 差 `<1e-3`，且与最近整数差 `<1e-3`；否则标为未收敛，不能四舍五入成整数。

每个 θ 点先计算 `gap_ε=min_n|λ_n−exp(iε)|`。固定 `gap_tolerance=1e-8`；当任一体隙不大于该值、块矩阵奇异、条件数 `>1e12` 或块结构不成立时，返回 `gapless_or_undefined`，不得补一个整数。特别保留 `a=0` 与 `a_c=π/14` 的奇点：`U(0)=+I` 和 `U(π)=−I`，不将奇点纳入整数计数。

## 四、验证顺序

### A. Chiral 和周期结构合同

- `S K S⁻¹ = −K`；
- TBC 周期性和 unitary；
- `U_step(0)=I`、`U_ε(0)=U_ε(T)=I`；
- 0／π 半周期块形式；
- 奇点拒绝路径。

### B. 静态极限（必须先通过）

静态拓扑采用 `T=2π/7`，并保留实际体隙：

- 静态拓扑 `μ0=0, μ1=0, ω=7`：预期 `|W0|=1, |Wπ|=0`；
- 静态平凡 `μ0=2.5, μ1=0, ω=7`：负 hopping 约定下 `bπ=2` 在实际 `k=0` 处产生 Floquet **0 隙**关闭，故 `W0=undefined`；π 支可以单独检查，但不能把 `bπ` 的下标误当成实际能隙；
- 静态平凡主对照采用 `ω=17`：两个体隙均开放时才检查 `|W0|=|Wπ|=0`。

若静态 winding 不成立，停止并回到公式和基底，不进入 kicked 或无序。

### C. 洁净 kicked 极限

`μ0=2.5, μ1=0.2, ω=7`，其中 `μ1` 是 onsite `K` 矩阵参数，等价于旧对称协议的两个 `exp[-2K(μ1)]` 半 kick；在 kick-map 的标量记号中为 `a=μ1=0.2`。无序模型的匹配 `K` 参数为 `rβ`，半 kick 旋转角为 `rβ`，完整对称旋转角为 `2rβ`；均匀均值控制使用 `K` 参数 `r`。曾误用 `2rβ` 作为矩阵参数的检查点已列入 `ERRATA.md`，不得用于结论。与既有端点量 `p0=pπ=1` 对照。只有实际计算的 `|W0|、|Wπ|` 与端点计数一致时，才记录洁净 kicked 验证通过；若不同，先检查定义和符号，不把预期值写成结果。

### D. 有限无序实现（仅 B、C 通过后）

复用既有固定序列 `default_rng(20261111+seed).random(320)[:N]`。先取 `N=80`、前 4 个 seed 和 `r=0.05,0.1,0.2`，逐实现记录 winding、块条件数、最近体模分离和边缘权重。均匀均值对照与无序实现分开，不能平均本征值后当成一个样品。

无序 winding 的量化、方差和通过与否必须与洁净 Bloch winding 分开描述。失败实现保留，不能通过改变种子、网格、奇点容差或候选阈值制造稳健性。

## 五、组件与验证文件

- `tbc_model.py`：chiral、TBC 键、周期化、块提取、winding 和奇点状态。
- `test_tbc.py`：上述结构合同与静态极限。
- `run_tbc.py`：静态、洁净 kicked 和经准入后的有限无序结果。
- `verify_tbc.py`：独立重建一个 TBC 传播、周期化因子和原始结果。
- 后续图件与报告：只有在真实数值通过后才生成，不为未通过方法包装结论。

所有测试含 `run_all_tests()` 和零测试保护，保存真实退出码、版本、输入参数和原始 JSON。旧 DEE、旧无序结果、旧主分支和旧全尺寸 `inconclusive` 均不修改。

## 六、停止条件和科学边界

- 静态拓扑／平凡未通过：停止，标 `static_baseline_failed`。
- 洁净 kicked 不一致：停止，标 `clean_floquet_baseline_failed`。
- 网格不收敛、奇异或奇点：标 `undefined`，不输出整数。
- 无序结果不一致：保留全部实现和均值对照，不宣称无序 winding 已被验证。

即使全部通过，也只支持当前有限二次型模型及参数域的数值拓扑证据，不是热力学极限、材料 `Tc`、相互作用、耗散、自洽配对、Meissner 或实验验证。

## 自审

- 周期起点、周期化分支、chiral 块结构、TBC 相位、奇点和收敛判据均显式定义。
- 先静态后 kicked 再无序，避免跨层级误用公式。
- 没有占位符、预设通过值或未经验证的 DEE／Bott 扩展。
- 设计与现有 Fock 校验和真实无序序列一致，不要求修改旧证据或主分支。
